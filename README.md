# Survivor

Jeu de survie à vagues en pixel art, façon *Vampire Survivors*, dans un seul fichier HTML.

## Jouer

Double-clique sur `index.html` (ou bouton **Jouer** dans T3 Code). Aucune installation.

- Déplacement : ZQSD / WASD / flèches · Pause : Échap
- 5 héros, 8 armes, 7 passifs, des coffres (bronze, argent, or) et des évolutions d'armes
- Évolution : arme au niveau max + son passif associé, puis ouvrir un coffre en argent ou en or
- Classement des parties enregistré localement dans le navigateur

Created in [T3 Code](https://t3.codes).
